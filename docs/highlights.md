# 《可视化导论》课程网站——亮点说明

> 课程讲解网站(静态站,中英双语):像参考书一样,让学生对照自学。
> 在线地址:https://wangling1206.github.io/vis-intro-course/#/
> 技术栈:Vite + React + TypeScript + ECharts + Three.js,部署于 GitHub Pages。

## 1. 内容:六章参考书式结构

| 章 | 标题 | 核心交互 |
|---|---|---|
| 1 | 走进可视化 | 安斯库姆四重奏、截断坐标轴实验 |
| 2 | 视觉感知与编码 | 四种编码对比、配色对比 |
| 3 | 数据与映射 | 比例尺切换、分箱粒度实验 |
| 4 | 基础统计图表 | 一数四图切换器 |
| 5 | 关系、网络与时空 | 力导向网络、时间窗口 |
| 6 | 高维、文本与交互叙事 | 投影噪声、四步数据故事 |

- 每章 = 学习目标 + 4 个知识块 + 章末自测(共 19 题,即时反馈)。
- 每知识块 = 讲解 + 代码块 + 渲染效果,三段纵排,顺序固定。
- 正文黑白书感:三档字号、无彩色气泡、无大黑点,中英逐段对照。

## 2. 核心亮点一:代码与效果联动

参数条同时驱动代码块与渲染效果,改一个参数,两边一起变:

- 安斯库姆四重奏:切换分组,代码 `series` 行与散点同步变化。
- 截断坐标轴:起点 0/100 切换,代码 `min` 行与柱形同步撒谎/诚实。
- 分箱实验:滑杆拖动,`binCount` 与直方图双峰同步出现/消失。
- 一数四图:切换视角,代码 `type` 行与图表同步切换。

实现:参数由 KnowledgeBlock 持有,`{{key}}` 模板经 ParamSpec.code 映射渲染,
DemoHost 把同一份参数透传给图表,天然同源,不可能不一致。

## 3. 核心亮点二:一套色板走完全站

- 唯一取色源 `styles/palette.ts`:品牌蓝 + 6 分类色 + 蓝单色渐变。
- 图表、Three.js 首页粒子、章节封面、交互强调四处同源。
- 彩虹色只在配色对比实验里作为反面教材出现一次。
- 正文保持黑白灰,颜色只服务于数据与交互。

## 4. 核心亮点三:首页 Three.js 数据管线

- 深底粒子流:原始散点 → 坐标轴对齐 → 聚合成柱/线隐喻,循环播放。
- 鼠标斥力 + 滚动视差,移动端自动降粒子数。
- 工程兜底:懒加载 three 首屏不阻塞,WebGL 不可用显示静态封面,
  `prefers-reduced-motion` 直接静态帧。

## 5. 工程亮点

- 原生双语:中英内联同一数据模型,缺译编译报错;图表内文本随语言重绘。
- 性能:11 个 Demo 按需动态 import,进入视口才挂载,离开即销毁。
- 部署:HashRouter + 相对路径 base,GitHub Actions 推 main 即部署,零 404。
- 可访问:语义标签、图表配文字小结、键盘可达、动效可关。
- 校验:中英 id 一一对应、色板唯一源、代码效果同源,三项 review 清单。

## 6. 自测与学习闭环

每章 3~4 道单选题,覆盖本章核心结论(如对数轴看增速、分箱决定结论、
饼图不超过 5 类、地图画比率)。答错即看讲解,完成态持久化,学生可对照查漏补缺。
