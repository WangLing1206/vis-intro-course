# 可视化导论 · 课程实践学习网站

《可视化导论》（陈为）课程实践学习网站：静态站点，原生中英双语，12 章课程内容，
每节由「知识 — 代码 — 实时渲染效果」构成，含 18 个可交互 D3.js 示例与 Three.js 首页粒子动效。

**在线访问**：https://wangling1206.github.io/vis-intro-course/

## 特性

- 纯静态、零构建、零依赖后端；D3 v7 与 Three.js 已本地化，可离线运行
- 中英双语一键切换（含全部正文与示例内文字），偏好本地记忆
- 首页粒子在「原始数据 → 清洗变换 → 可视化编码 → 渲染 → 交互」五阶段间形变
- 章节内嵌可运行示例：Anscombe 四重奏、流水线、视觉通道、格式塔、标度、
  条形/折线/散点/饼图、力导向图、树图、散点图矩阵、平行坐标、河流图、
  日历热力图、词云、刷选联动、综合仪表盘
- 响应式布局、滚动渐入动效、阅读进度条、代码语法高亮

## 运行

```bash
# 任意静态服务器即可，例如：
python -m http.server 8000
# 打开 http://localhost:8000
```

## 结构

```
index.html          入口
assets/css/         样式
assets/js/          应用逻辑、课程内容（content1/2.js）、首页动效（hero.js）
assets/js/vendor/   d3.min.js、three.module.js（本地化依赖）
demos/              18 个独立交互示例（iframe 内嵌）
```
